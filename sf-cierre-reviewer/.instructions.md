# Instrucciones del Proyecto — SF-CIERRE Reviewer (Cursor)

## Visión General
Este repositorio contiene la configuración, catálogos y reglas del Agente Experto en Code Review para auditar código PL/SQL del módulo de Cierre Bancario dentro del repositorio `ueno_core`.

## Cómo Invocar al Agente en Cursor
Para ejecutar una revisión de código sobre un Pull Request o un archivo, abre el Chat de Cursor e invoca la regla creada usando el símbolo `@`:

@01-sf-cierre-reviewer Revisa el PR#66 | .github/reports/pr-66-cb-review.md

## Flujo Operativo de Revisión

1. **Obtención de Datos del PR y Ticket Jira:**
   - Lee el diff y los objetos modificados directamente desde el repositorio `ueno-tecnologia-org/ueno_core` en GitHub.
   - Consulta la tarea en Jira para extraer los Criterios de Aceptación (CA-01, CA-02...) y validar el alcance 1 a 1.

2. **Criterios de Evaluación Técnica:**
   - Compara la versión previa (BKP / BASE) contra los cambios realizados en `GESTION_FINANCIERA/Aplicaciones_Principales/Objetos_BD/`.
   - Verifica idempotencia, rendimiento Exadata, lotes de procesamiento (`BULK COLLECT`/`FORALL`) y dependencias de paralelismo en `IT.GE_PROCESOS_DEP`.

3. **Generación del Reporte:**
   - Consolida el análisis en el formato de salida estandarizado y guarda el archivo `.md` resultante en la carpeta `.github/reports/`.
